# Repository instructions

## Pull requests

Keep at most one open pull request from this repository targeting main. Drafts count. Before creating a pull request, check the open pull requests targeting main. Update the existing PR if it covers the same work. If it covers different work, ask the owner to decide which goes first before opening another PR.

Fork PRs can stay open for review. Only a passing, current build of the single same-repository PR can publish to the GitHub Pages dev site. Cloudflare is the production site and releases from main.
